# BudDeals
Windows desktop app: Python 3.12 + pywebview (WebView2) window around `ui/index.html`; PyInstaller onedir + Inno Setup; same release/auto-update pattern as LoLStat.
- `app.py` window + JS API (store, scan, sign-in window, read rewards, auto-update). Bump `APP_VERSION` for every release; the commit message becomes the release notes.
- `scan.py` v2: stores = Leafly city listing (`leafly_stores`, reads pages in batches of 4 since it is sorted by Recommended, storefronts only) merged with OSM shop=cannabis (`osm_cannabis`, `_merge_stores` dedupes). Area cache key `L2:`. Menus: per-chain `RECIPES` (MÜV per-store `/locations/<city>/menu/menu/...`, Trulieve `/category/{flower,vapes,concentrates,edibles}`, Sunnyside/Green Dragon generic crawl) read once per chain via the nearest store; otherwise the store own website (`leafly_website()` finds it from its Leafly page, cached in cache.json `web`; generic crawl follows embedded menus like Dutchie/Jane via EXTRACT `embeds`), websites found via `find_website()` (chain list → Leafly page → DuckDuckGo/Bing search, cache `web` key `s:<slug>`); `read_site` tries /menu,/shop,/order-online… when nothing found and saves `dbg` notes for 0-product sites. When a site shows no menu, `ordering_menu()` finds the store Dutchie/Jane/Weedmaps ordering store via web search (cache `plat`, 7 days) and reads it (`read_menu_pages`). Leafly menus only if `S.leaflyBackup` (off by default). Cache key per source (`muv`, `trulieve`, `leafly:<slug>`). Cache: `%APPDATA%\BudDeals\cache.json`.
- `app.py` `BrowserReader` (hidden WebView2 windows): `GATE_JS` answers state (store own state, else searched area; names or 2-letter codes; dropdowns + Enter)/age/terms/store screens (age+terms only if `S.agree`), `EXTRACT_JS` finds the product grid and reads Currently/Formerly/struck prices, `LOAD_MORE_JS` (ctx `more`), `next_data()` for Next.js page data.
- `desktop.py` tray icon (pystray), Windows notifications, start-with-Windows (HKCU Run, `--tray` starts hidden), QR codes (qrcode). Closing the window hides to tray when `S.tray`.
- `ui/index.html` UI (calls `window.pywebview.api`): cache-first `api.cached()` then live `api.scan()` with `window.onSiteResult` per store; a new search or the ■ Stop button calls `api.stop_scan()` (cancel Event checked by `scan.scan` and `BrowserReader.stopped`; `scanGen` drops stale results); `#pbar` loading bar fed by `onScanProgress(done,total,stage)` (stages stores → websites → menus); Settings tab state lives in `S` (store.json). `ui/js/dealparse.mjs` deal parser/ranking; `priceCart(items, deals)` stacks store deals in the cart (item deals: category %/BOGO/buy X get Y/N for $X on non-sale items unless the text says it stacks; then the best spend-$X tier on what is left; "cannot be combined" deals tried alone; returns lines + "add $X more" hint).
- Filters panel (`S.f`, `fOk()`): size, strain type, min THC/terpene/CBD %, terpene name, brand, max price, on sale. Product category = `primaryCat()` (name rules first, then store/Leafly category, then URL; leftovers go to an "Other" chip). Multi-size cards keep the lowest price plus `hi` (shown as "Sizes $a–$b"); an unlabeled, un-struck second price is a size, not a sale. Site crawl reads up to 18 pages incl. every category link (edibles, tinctures, topicals, accessories).
- UI: left sidebar nav + top bar (location, radius, cart pill). Light theme default (`S.theme`). Tabs: Deals (store columns `S.view='stores'` or one list; product rows with Add to cart / View product (`p.url`)), My cart (`S.cart`, per-store totals, store-deal thresholds, ✓ I bought these → `S.orders`), Budget, Shopping list, My orders (liked/dislike/buy-again, `stockCheck()` back-in-stock alerts via `S.stock`), Stores, Map, Rewards, Spending, Add a deal, Settings.
- Price history per product in cache.json `hist` (60 days) → `isLow`, `inflated`, `typical`.
- `.github/workflows/build.yml` builds `BudDeals-Setup.exe` on push to main → GitHub Release (tag v<version>).
- `installer.iss` per-user install to %LOCALAPPDATA%\Programs\BudDeals.
- Checks: `python -m py_compile app.py scan.py desktop.py`; parser: `node -e 'import("./ui/js/dealparse.mjs").then(p=>console.log(p.parseDeal("Spend $200 get 50% off")))'`
- User data (store.json, wallet, sign-in cookies) stays on the PC — never upload it.
